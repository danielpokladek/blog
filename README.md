# Tech Stack

- [Hugo](github.com/gohugoio/hugo) - Static site generator.
- [Blowfish](https://github.com/nunocoracao/blowfish) - Theme used with Hugo.
- Automatic deployment to GitHub Pages using GitHub Actions.
